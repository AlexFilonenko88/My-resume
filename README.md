# Резюме — Алексей Филоненко

Одностраничное резюме начинающего Bitrix-разработчика: адаптивная семантическая
вёрстка без фреймворков.

**Демо:** https://alexfilonenko88.github.io/My-resume/

## Стек

- HTML5, CSS3 (flexbox, адаптив, print-стили)
- Шрифты Google Fonts (Montserrat)
- Prettier для форматирования

## Структура

```
index.html      — разметка страницы
css/style.css   — стили (десктоп, планшет, мобильный, печать)
img/            — фото, favicon
```

## Локальный запуск

Открыть `index.html` в браузере или поднять Live Server (порт 5501 настроен
в `.vscode/settings.json`).
